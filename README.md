# 🎯 Custom Radio Selection UI

Uma interface moderna de **seleção de opções (Custom Radio Buttons)** desenvolvida com **HTML5** e **CSS3**, focada em simplicidade, elegância e experiência do usuário. O projeto apresenta um sistema visual de escolha única, ideal para formulários, cadastros, questionários, pesquisas e configurações de perfil.

---

## 📸 Visão Geral

O layout consiste em um cartão centralizado contendo uma lista de opções selecionáveis. Cada item utiliza um design personalizado para substituir os tradicionais Radio Buttons do navegador, proporcionando uma aparência mais moderna e profissional.

A opção selecionada recebe destaque visual através de cores contrastantes e efeitos de profundidade, facilitando a identificação da escolha atual.

## 🧩 Componentes da Interface

### 🔹 Cabeçalho

Área superior responsável por apresentar o objetivo da seleção.

**Funções:**
- Orientar o usuário
- Destacar a ação principal
- Criar hierarquia visual

---

### 🔹 Opções de Seleção

Lista de alternativas disponíveis para escolha.

**Exemplos exibidos:**

- 🎮 Gamer
- 🎥 YouTuber
- 🎓 Student
- 💻 Developer

**Características:**
- Apenas uma opção pode ser selecionada por vez
- Indicador visual circular
- Destaque automático para item ativo
- Navegação intuitiva

---

### 🔹 Estado Selecionado

Quando uma opção é escolhida:

- Fundo recebe destaque escuro
- Texto torna-se mais evidente
- Indicador circular é ativado
- Sombra suave reforça a profundidade do elemento
